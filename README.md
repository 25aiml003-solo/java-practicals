## Structure

- `Practical-1/` through `Practical-13/` — practical source code and supporting material.
- `MiniBank/` — project source code and documentation.
- `Word-File/` — practical reports, where applicable.

## Requirements

- JDK 17 or later (JDK 21 recommended).
- Visual Studio Code, IntelliJ IDEA, or another Java IDE.

## Compile and run

```powershell
javac Example.java
java Example
```

Replace `Example` with the class name containing `main`.
