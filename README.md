A repository containing Java practical programs, the MiniBank console project, and practical reports.

## Repository contents

- `Practical-1/` through `Practical-13/` — 58 Java source files covering OOP, exceptions, collections, file handling, generics, and multithreading.
- `Practical-6/DiscountEngine/` — discount-rule example project.
- `MiniBank/` — 21 Java source files organized into model, repository, service, exception, utility, annotation, and concurrency packages.
- `Word-File/` — 13 practical reports in DOCX format.

## Requirements

- JDK 17 or later (JDK 21 recommended).
- Visual Studio Code, IntelliJ IDEA, or another Java IDE.

## Compile and run a standalone practical

Open PowerShell in the folder containing the source file:

```powershell
javac Example.java
java Example
```

Replace `Example` with the public class name containing `main`.

## MiniBank

See [MiniBank/README.txt](MiniBank/README.txt) for project-specific information and run instructions. Compile the package-based source from the `MiniBank` directory using the instructions in that file.
